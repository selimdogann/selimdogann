### Selected projects

| Project | What it does |
|---|---|
| **[Arşiv Zekâsı](https://github.com/selimdogann/arsiv-zekasi-graphrag)** | Local GraphRAG for legal and corporate archives. Hybrid retrieval (embeddings + BM25, fused with RRF), entity extraction into a knowledge graph, then Dijkstra over `-log(confidence)` edge weights so the shortest path is the most reliable chain of evidence. Every answer cites its source document. |
| **[Kargo Rota Optimizasyonu](https://github.com/selimdogann/kargo-rota-optimizasyonu)** | Capacitated Vehicle Routing solved with a genetic algorithm, A\* pathfinding over a real road network (not straight-line distance), and knapsack-based vehicle loading. |
| **[Kocaeli Haber Haritası](https://github.com/selimdogann/kocaeli-haber-haritasi)** | Scrapes local news sites, classifies articles with sentence-transformers, geocodes the places they mention and plots them on a map. |

| **[Maaş Radar](https://github.com/selimdogann/maas-radar)** | Anonymous salary-sharing platform for Turkey, so people can benchmark pay before negotiating. |
